# The Brave Digger
Prototype for a puzzle/mystery game about navigating a cemetery to find your friend, who's been buried alive, before they run out of air.

`yarn start` serves the game at http://localhost:9000.

Branched from Corn Maze Tycoon (see `main`). `AIBrain.js` and `Player.js` aren't wired in yet, but are kept for NPCs: generated levels use the same `width`/`height`/`grid` shape that `AIBrain` reads.
